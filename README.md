# CSC584-Individual-Assignment-1.
This is my first individual assignment for CSC584 that collects user profile details via an HTML form.
Personal Profile Web Application

Project Description

This project is developed for CSC584 Individual Assignment 1.

The application allows students to submit their personal information (Name, Student ID, Programme, Email, Hobbies, and Self-Introduction) using a modern, styled HTML form. The data is submitted via HTTP POST to a Java Servlet, which securely processes the information and forwards it for dynamic display on a styled JSP page.

Technologies Used:
-HTML5
-CSS3
-Java SE / Java EE
-Java Servlet (ProfileServlet.java)
-JavaServer Pages (profile.jsp)
-NetBeans IDE
-GlassFish Server

Features:
-Personal information input form with helpful placeholder examples.
-Secure data handling by using HTTP POST method.
-Backend data processing using Java Servlets.
-Dynamic profile rendering on a JSP page using Expression Language.
-Modern and responsive CSS styling featuring a warm beige theme and smooth typography.

How to Run:
-Open the project folder in NetBeans IDE.
-Ensure GlassFish Server is configured and running.
-Right-click the project and select Clean and Build.
-Right-click the project and select Run.
-Fill out the profile form fields in the browser and click Submit Profile to view the output card.
